§1 — Single Processing Element (PE) Internal Architecture

Lower Unit inputs
Q[t] d-vector (horizontal) K[t] d-vector (vertical, stationary)
score_i = Q · K[t]
Serial: d multiply-accumulates over d cycles.
n MACs time-interleaved → stagger = ⌈d/n⌉
Upper Unit inputs
score_i (from Lower) (M,L,O)ᵢₙ (from left neighbor) V[t] d-vector (vertical)
Mout = max(score, Min)
α = exp(Min − Mout) β = exp(score − Mout)
Lout = Lin·α + β
Oout = Oin·α + β·V
Two exp lookups in parallel + ⌈3d/w⌉ MAC cycles.
Column dwell formula
lower_lat = d
upper_pe = exp_lat + ⌈3d / mac_w⌉
column_dwell = d + upper_pe
Both Q's horizontal progress and
K's vertical propagation run at column_dwell rate.
